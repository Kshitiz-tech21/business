# 🤝 Service Level Agreement (SLA)

## 1. Availability
- **Uptime Goal**: 99.9% availability for the API and Dashboard.
- **Maintenance**: Scheduled windows on Sundays 02:00 - 04:00 UTC.

## 2. Performance Targets
- **API Response**: 95% of read requests resolved under 200ms.
- **Analysis Execution**: Simple SQL queries resolved under 5s.
- **AI Reasoning**: Supervisor routing resolved under 2s.

## 3. Support Tiers
- **Pro**: Email support (24h response).
- **Enterprise**: Dedicated Account Manager + Slack channel (4h response).

## 4. Data Integrity Guarantee
- **Backups**: Daily snapshots of PostgreSQL.
- **Recovery**: RPO (Recovery Point Objective) of 24h; RTO (Recovery Time Objective) of 4h.
