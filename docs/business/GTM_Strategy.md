# 📈 Go-To-Market (GTM) Strategy

## 1. Positioning
**The "Trustworthy AI Analyst"**. Unlike general-purpose LLMs, this platform provides a governance layer that prevents data loss and ensures SQL accuracy via human-in-the-loop verification.

## 2. Pricing Model (SaaS Tiers)
| Tier | Target | Pricing | Key Features |
| :--- | :--- | :--- | :--- |
| **Free** | Individual/Dev | $0/mo | 1 Project, 5 datasets, Local LLM. |
| **Pro** | SMB / Growth | $49/mo | 10 Projects, Cloud LLM, PDF Reporting. |
| **Enterprise** | Large Org | Custom | Unlimited, SSO, Dedicated Worker, SLAs. |
